# Bidra til IOP Målbygger

Takk for interessen i å bidra til IOP Målbygger! 🎉

## 🐛 Rapporter bugs

Hvis du finner en feil:
1. Sjekk om det allerede finnes en issue
2. Opprett en ny issue med:
   - Tydelig beskrivelse av problemet
   - Steg for å reprodusere
   - Forventet vs faktisk oppførsel
   - Skjermbilder hvis relevant

## 💡 Foreslå forbedringer

Har du en idé? Åpne en issue med:
- Beskrivelse av forslaget
- Hvorfor det vil være nyttig
- Eventuelle eksempler

## 🔧 Pull Requests

1. **Fork** repoet
2. **Opprett en branch:** `git checkout -b feature/amazing-feature`
3. **Commit endringer:** `git commit -m 'Add amazing feature'`
4. **Push til branch:** `git push origin feature/amazing-feature`
5. **Åpne en Pull Request**

### Retningslinjer:
- Følg eksisterende kodestil
- Test endringene dine
- Oppdater dokumentasjon hvis nødvendig
- Beskriv tydelig hva PR-en gjør

## 📝 Kodestil

- TypeScript/React best practices
- Tailwind CSS for styling
- Beskrivende variabelnavn på norsk der det gir mening
